# Assets — plan, budget, and license ledger

**Budget: <$100 total. CC0 preferred. Every imported asset gets a ledger row
in the same change that adds it.** This file is our legal cover at Steam
submission — keep it accurate.

## Plan

- **Phase 1 ($0, M1)**: Kenney CC0 packs — "Top-down Tanks Redux" (tanks,
  barrels, bullets, terrain), a Kenney UI pack, Kenney audio (impact/UI SFX).
  CC0 = public domain, Steam-safe, no attribution required (we credit anyway).
- **Phase 2 (~$40–80, pre-Steam polish)**: one cohesive paid pack (VFX or
  restyle) and/or commissioned capsule art for the store page. Decide after
  friends feedback at M5.
- Music: CC0/CC-BY sources (Kenney, FreePD, OpenGameArt with per-track
  vetting) before considering paid.

## Rules for agents

1. Download from the official source; record exact URL + license at import.
2. CC-BY requires an in-game credits entry — add it in the same change.
3. No Unity Asset Store assets whose EULA restricts redistribution in builds
   (standard Asset Store license is fine for shipped games; extension assets
   are per-seat and must not be committed).
4. Never commit paid-asset source files to the public repo unless the license
   explicitly allows redistribution in source form — if unclear, keep them
   out of git and document retrieval in this file.
