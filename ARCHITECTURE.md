# Potshot Architecture

## System overview

```
 Mac/Win clients (Unity)                        tow-c1 (Linode LKE, us-sea-2)
 ┌──────────────────────┐   UDP 7777            ┌────────────────────────────────┐
 │  Potshot client      │──────────────────────▶│ node (hostPort 7777/udp)       │
 │  FishNet + Tugboat   │  potshot.kodloki.io   │  └─ pod: potshot-server        │
 └──────────────────────┘  → node public IP     │     (headless Linux, FishNet)  │
                                                │                                │
 Browser ─── HTTPS ────▶ ingress-nginx ────────▶│  status endpoint (players,     │
             potshot.kodloki.io (LB 172.232.176.47)  version, uptime)            │
                                                └────────────────────────────────┘
```

- **One Unity project** (`game/`) builds both the client (Mac/Win) and the
  dedicated server (Linux headless, Dedicated Server build target).
- **Server-authoritative simulation**: clients send inputs; the server owns
  tanks, projectiles, and damage. Client-side prediction on the local tank,
  snapshot interpolation (~100 ms) for remote entities. Tick rate 30 Hz.
- **Transport**: FishNet Tugboat (raw UDP) now; FishySteamworks (Steam
  Datagram Relay) added at M6 alongside it. Game code stays transport-agnostic.
- **Why hostPort, not LoadBalancer**: standard LKE NodeBalancers do not
  support UDP (Premium/LKE-E only). Game traffic goes straight to a pinned
  node's public IP; a CronJob reconciles the `potshot.kodloki.io` A-record
  against the node IP via the Linode API. HTTP status traffic uses the normal
  ingress + cert-manager path. Details: `docs/deployment.md`.
- **Version handshake**: server rejects clients whose build version doesn't
  match; Steam auto-updates make this invisible at M6.

## Key decisions log

- Unity + FishNet over Godot/Mirror/NGO: built-in client-side prediction,
  swappable transports, headless Linux builds. (2026-08)
- Dedicated server over P2P/host-client: no NAT pain, fits existing cluster,
  one source of truth for physics. (2026-08)
- No matchmaker/Agones: one persistent arena server for ~10 friends. (2026-08)
- Zero-editor-GUI constraint: see `CLAUDE.md` Prime Directive. (2026-08)
